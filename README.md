# Tueste Norte

Página web de una cafetería de especialidad creada como proyecto de aprendizaje.

## Tecnologías utilizadas

- HTML5 para la estructura.
- CSS3 para el diseño.
- JavaScript para la interacción y validación.
- PHP para recibir y comprobar los datos del formulario.

## Funcionalidades

- Navegación entre las secciones de la página.
- Catálogo de cafés presentado mediante tarjetas.
- Información de las catas que puede mostrarse y ocultarse.
- Formulario de contacto con validación.
- Procesamiento seguro de los datos mediante PHP.

## Ejecución local

1. Instalar XAMPP.
2. Colocar la carpeta `tueste-norte` dentro de `C:\xampp\htdocs`.
3. Iniciar Apache.
4. Abrir `http://localhost/tueste-norte/` en el navegador.

Proyecto educativo realizado durante la primera semana de prácticas.
